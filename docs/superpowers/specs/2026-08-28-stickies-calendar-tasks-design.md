# 闪签：日历驱动任务重构

> 状态：**已批准，待写实现计划**  
> 日期：2026-08-28  
> 取代：便签墙交互（见 `2026-08-28-sparknotes-stickies-design.md`）；本版为破坏性产品转向  
> 参考：嘀嗒清单（任务 + 日/周/月日历）

## 目标

将「闪签」从彩色便签墙重构为 **以日历为中心的个人任务应用**：

- 主界面为 **日 / 周 / 月** 三档日历（第一版齐备）
- 事项升级为真正的 **任务**（标题、完成、优先级、日期/时间、提醒、备注）
- 任务 **必须有日期**；新建默认挂到选中日（无选中则今天）；不做「未安排」收集箱
- **新建 Task 模块**，整包退役 Sticky 便签实现与数据（不迁移）
- 对外仍叫「闪签」，路由/slug 保持 `stickies`，对内实现名为 tasks

## 已拍板决策

| 议题 | 结论 |
|---|---|
| 产品中心 | 日历（非便签墙、非智能列表） |
| 事项模型 | 真实任务，非便签 |
| 无日期任务 | 不允许；创建默认今天/选中日 |
| 日历视图 | 日 + 周 + 月，第一版齐备 |
| 任务字段 v1 | 标题、完成、日期、优先级、具体时间、提醒、备注 |
| 不做（v1） | 标签、子任务、重复、AI、未安排、智能列表、归档库 |
| 旧便签数据 | 不迁移，直接废弃 |
| 实现路径 | **方案 2**：新建 Task 模块，stickies 实现整包退役 |
| 对外命名 | 仍叫「闪签」；内部模块/表用 `tasks` |
| API 前缀 | 继续 `/apps/stickies`（工作台链接不变） |
| 列表查询 | 日历主查询用时间区间 `from` / `to` |
| 详情编辑 | 右侧侧栏；快速创建不自动打开侧栏 |
| 拖拽 | v1 纳入：改日期 / 改时刻 |
| 已完成展示 | 默认显示但弱化；可选「隐藏已完成」 |
| 提醒 | 复用现有触达方式（App 内 + 浏览器 Notification），调度挂到 Task |

## 产品定位

**一眼看见哪天有什么事，在日历上直接完成与改期。**  
比便签墙更适合「日程感」；比完整项目管理更轻——个人、必有日期、无列表侧栏。

### 业界参考

| 产品 | 借鉴 |
|---|---|
| 嘀嗒清单 | 日/周/月切换、任务挂日历、勾选完成、拖拽改期 |
| 本版刻意不做 | 收集箱、清单/标签体系、习惯打卡、番茄钟、协作 |

## 信息架构

```text
┌─────────────────────────────────────────────────────────────────┐
│  闪签    [日|周|月]   ‹  范围标题  ›   [今天]   隐藏已完成  🔔   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│                    日历画布（日 / 周 / 月）                         │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│  ＋ 添加任务…（回车 → 挂到 selectedDate，默认全天）                 │
└─────────────────────────────────────────────────────────────────┘
         点击任务 → 右侧详情侧栏（遮罩 + Esc 关闭）
```

- 包在现有 `WorkbenchShell` 内；入口仍为 `/workbench/apps/stickies`
- **唯一主壳是日历**；不做侧边智能列表、不做便签网格

### 三视图行为

| 视图 | 展示 | 创建 |
|---|---|---|
| 月 | 格子内当天任务摘要（标题 + 优先级色点）；溢出 `+N` | 点格子更新 `selectedDate`；顶栏/底栏「+」或输入创建 |
| 周 | 7 列；全天任务置顶；有时刻的按时间轴排 | 点时间轴空白可带出日期 + 时刻（非全天） |
| 日 | 单日时间轴 + 全天区 | 同周，粒度更细 |

### 选中日与「今天」

- 全局 `selectedDate`；打开应用默认今天
- 「今天」：视图滚回包含今天的范围，并选中今天
- 翻页不强制清空选中日

## 数据模型

### 退役

- 删除实现：stickies controller/service/AI/reminder/notifications、前端便签组件与相关样式
- Prisma：`DROP` `sticky_notes`、`sticky_notifications`（及 enum 若仅便签使用）
- Shared：移除 Sticky 相关 Zod schema；新增 Task schema
- App registry：对外 name 仍「闪签」，描述改为日历任务；slug 仍 `stickies`
- 管理端 `/admin/apps/stickies`：文案改为任务/日历能力，去掉 AI/便签表述

### `Task`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | cuid | |
| `tenantId` / `userId` | string | 隔离，同现有 apps |
| `title` | string | 必填 |
| `notes` | text | 可选备注 |
| `completed` | boolean | 默认 false |
| `completedAt` | DateTime? | 完成时写入 |
| `priority` | enum | `high` \| `medium` \| `low`，默认 `medium` |
| `dueAt` | DateTime | **必填**；API 存 UTC ISO。全天任务：`dueAt` = 用户本地该日 00:00 对应的 UTC 瞬间，展示只取本地日历日 |
| `allDay` | boolean | true = 无具体时刻，出现在全天区 |
| `reminderAt` | DateTime? | 可选 |
| `reminderFiredAt` | DateTime? | 已触发标记 |
| `sortOrder` | int | 同日内排序 |
| `createdAt` / `updatedAt` | DateTime | |

索引建议：`(tenantId, userId, dueAt)`；`(tenantId, userId, reminderAt)`（未触发扫描）。

### `TaskNotification`

对齐原 `StickyNotification` 形状：`id`, `tenantId`, `userId`, `taskId`, `message`, `firedAt`, `read`。

## API

前缀：**`/apps/stickies`**（对外不变）。守卫继续校验闪签 app 启用状态。

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/tasks?from=&to=` | 区间内任务（主日历查询）；可选 `includeCompleted=false` |
| `POST` | `/tasks` | 创建；缺 `dueAt` 时服务端默认「今天」全天 |
| `GET` | `/tasks/:id` | 单条 |
| `PATCH` | `/tasks/:id` | 更新（含完成、拖拽改期） |
| `DELETE` | `/tasks/:id` | 硬删除 |
| `GET` | `/notifications?unread=` | 未读/全部 |
| `PATCH` | `/notifications/:id/read` | 标已读 |
| `POST` | `/notifications/read-all` | 全部已读 |

旧 `/notes`、`/ai/*` 端点删除，不再兼容。

提醒调度：BullMQ/现有扫描逻辑改为扫 `Task.reminderAt`，写入 `TaskNotification`。

## 交互细节

### 快速创建

- 输入条占位：「添加任务…」；Enter 创建
- 日期 = `selectedDate`；默认全天、`priority=medium`
- 周/日点击空白时段：预填该日 + 时刻，`allDay=false`
- 创建成功后 **不** 自动打开侧栏

### 详情侧栏

- 可编辑：标题、完成、日期、全天、具体时间、优先级、提醒、备注
- 保存：防抖或失焦自动保存（对齐原便签习惯）
- Esc / 点遮罩关闭

### 完成

- 日历行与侧栏均可勾选；乐观更新 + `PATCH`
- 已完成：划线或降透明度
- 工具栏：「隐藏已完成」→ 请求带 `includeCompleted=false`（服务端过滤，避免大区间拉无用数据）

### 拖拽（v1）

- 月：拖到另一天 → 改 `dueAt` 日期，保留时刻与 `allDay`
- 周/日：拖到另一时段 → 改日期+时间，设 `allDay=false`
- 不做拖拽改「时长」（任务不是带 duration 的事件块）

### 提醒

- 侧栏设置 `reminderAt`
- 到点：通知记录 + 浏览器 `Notification`（需权限）
- 顶栏铃铛保留

### 空态

- 某日无任务：轻提示可点击添加
- 新用户：日视图一句引导「在今天添加第一个任务」

## 视觉原则

- 在现有 workbench 设计体系内；**去掉**彩色便签卡片墙
- 日历为主构图；任务行可扫读
- 优先级用克制色点或左边线；避免紫光、重阴影、装饰 emoji 堆砌
- 日/周时间轴、月格子密度参考嘀嗒清单：信息优先

## 权限与管理端

- App 启停、ACL 与现网一致；未启用时不可访问 API/页
- Guard 可保留 stickies slug 校验；类名可逐步改为中性命名（非必须）

## 明确不在本版

- AI 解析 / 改写 / 摘要
- 标签、子任务、重复规则
- 未安排收集箱、今日/计划等智能列表
- 旧便签数据迁移
- 邮件/企微等提醒渠道扩展
- 任务协作与共享

## 成功标准（验收）

1. 日 / 周 / 月可切换，`from`/`to` 区间内任务显示正确  
2. 新建任务必有日期（默认选中日或今天）；侧栏可改齐标题、完成、日期、优先级、时间、提醒、备注  
3. 月视图拖拽改日、周/日拖拽改时可用  
4. 提醒到点出现通知；铃铛可标已读  
5. 旧便签 API/UI 不可达；旧表已删除；无便签数据迁移  

## 实现备注

- 前端建议拆：`CalendarShell`、`MonthView` / `WeekView` / `DayView`、`TaskChip`、`TaskDetailDrawer`、`QuickAdd`；状态以 `selectedDate` + `view` + `rangeTasks` 为中心
- 时区：以用户本地日界解释「全天」与「今天」；API 存 UTC ISO，文档约定转换点，避免全天任务漂移
